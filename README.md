# Hover effects lab

A standalone page for comparing hover fidgets on client logos (and a headline). Canvas effects plus a GSAP family.

Open it locally:

```bash
python3 -m http.server 8766
```

Then go to [http://localhost:8766](http://localhost:8766).

GSAP loads from a CDN, so the first load needs a network connection. Star the ones you like. Per-card Settings tune that effect only.
