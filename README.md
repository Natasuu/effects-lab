# Hover effects lab

A page for trying hover fidgets on logos and on a headline. Canvas physics in one family, GSAP tweens in the other.

**Open the lab:** [natasuu.github.io/effects-lab](https://natasuu.github.io/effects-lab/)

Move your cursor over a card. Star the ones you like. Open Settings on a card to tune that effect only.

## What’s in here

- **Logos / Headline.** Same effects on client marks or on letter-by-letter type.
- **Family.** All, Canvas, or GSAP.
- **All radius / All strength.** Shared, unless you override a card.
- **Auto cursor.** Walks the pointer for you.

The logos are trademarks of their owners. They are demo subjects, not something to reuse.

GSAP loads from a CDN, so the first visit needs a network connection.

## Run it locally

```bash
python3 -m http.server 8766
```

Then open [http://localhost:8766](http://localhost:8766).
