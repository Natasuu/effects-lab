# GSAP hover signatures still missing

Scope is hover fidgets that can run on the lab’s image tiles or headline letters, using GSAP core, plugins already on the page, or other plugins that are free as of 10 October 2026. `index.html` loads `gsap@3.13.0` plus CustomEase, InertiaPlugin, and CustomWiggle from jsDelivr. Cards already shipped, and excluded here: GSAP elastic scale, explode, scramble, 3D flip (`rotationX` / `rotationY` toward the cursor), CustomWiggle shiver, InertiaPlugin throw, swap places, quickTo orbit, stagger cascade with `bounce.out`, and velocity skew smear. Canvas cards also excluded as re-skins: magnetic lean, dock zoom, jelly, ripple, shatter, glitch, black hole, echo, pluck, melt, drop, filings, bulge, pinch, glow, focus, spotlight, duotone, VHS, ASCII, pixelate, highlighter, sand, swirl, lens, wave, 3D tilt, confetti, scatter.

As of the 29 April 2025 GSAP 3.13 post, every former Club plugin is free for commercial use, including SplitText, MorphSVG, and the rest of the bonus set. The docs index lists DrawSVG, MorphSVG, MotionPath, SplitText, Flip, and Draggable as CDN plugins. None of the twelve below need a paid membership. Several need a script the page does not load yet. Each of those names a core-only fallback.

## Which GSAP hover demos from 2020–2026 are still missing?

### Takeaway
Twelve signatures from GSAP docs, the official Flip pen, Codrops (2020–2025), and one May 2025 forum thread are still absent. The ones that show off a GSAP feature the lab does not already use are masked text, Flip reflow, DrawSVG, MotionPath, and a distance color fill. Squash-and-stretch, a rolling counter, and a character marquee were asked about and were not found as sourced hover fidgets.

### Cited Findings

Each entry: what the pointer does, which GSAP feature carries it, letters, tiles, one-line non-duplication reason, source. Plugin cost is the 3.13 post unless noted.

1. **Masked stagger wipe.** Pointer enter slides each letter up through an overflow clip; leave reverses the same tween. Feature: SplitText `mask: "lines"` (also `"words"` or `"chars"`) plus a core `yPercent` stagger. The 14 May 2025 Codrops article sets `mask: "lines"` and, on a button click, runs `gsap.fromTo` from `yPercent: 110` to `0` with a per-type `duration` and `stagger`. The author says the same tweens can be bound to scroll or load. SplitText docs (v3.13.0+) define `mask` as an extra wrapper with `visibility: clip`. Letters: yes. Tiles: yes if each tile is wrapped in its own overflow clip and tweened the same way, with no SplitText. Not a duplicate: cascade drops pieces with `bounce.out` and no clip, so the type never hides behind a line box. Free fallback: hand-built overflow wrappers. Knob: stagger and `yPercent`. — [Codrops, 14 May 2025](https://tympanus.net/codrops/2025/05/14/from-splittext-to-morphsvg-5-creative-demos-using-free-gsap-plugins/); [SplitText](https://gsap.com/docs/v3/Plugins/SplitText/)

2. **Kinetic row tracking.** Pointer move shifts rows of letters, or an image grid, along x with lag; leave eases the offset back to 0. Feature: core `x`, implemented with `gsap.quickTo` (the docs’ mouse-follower uses `duration: 0.6`, `ease: "power3"`, and fades the follower out on document `mouseleave`). Codrops, 29 May 2024, describes rows of text moving with the mouse on a rotated stage, and says the author tried the same idea on an image grid with filter animations. A separate click sends the center image fullscreen. Letters: yes. Tiles: yes, the article states the image-grid variant. Not a duplicate: orbit uses quickTo to circle the cursor; magnetic lean is a canvas tilt-and-grow; this is a lagged 1D shift of the row. Knob: follow duration (the lag). The article’s filter animations should be left off, or the card collides with focus and duotone. — [Hover Motion Intro](https://tympanus.net/codrops/2024/05/29/hover-motion-intro-animation/); [gsap.quickTo()](https://gsap.com/docs/v3/GSAP/gsap.quickTo()/)

3. **FLIP flex fidget.** Pointer enter adds a class that grows one cell’s `flex-basis` to `calc(150% - 5px)` and grows its row; leave removes the classes. Both directions call `Flip.getState` then `Flip.from` with `duration: 1` and `absolute: true`. Feature: Flip. The pen listens to `mouseenter` and `mouseleave`. A 6 October 2022 forum reply from Rodrigo says mouse enter/leave is a valid Flip trigger. Letters: only if each letter is a flex item whose basis changes. Tiles: yes, the pen is colored flex cells. Not a duplicate: swap tweens two pieces to each other’s coordinates; dock zoom is canvas scale by distance; Flip records a real layout change and animates the reflow. Knob: duration, and the flex growth ratio. Extra script. Core fallback: tween `flexBasis` directly and accept that neighbors pop instead of sharing one FLIP measurement. — [Flip/Flex Hover Interaction](https://codepen.io/GreenSock/pen/jEbpKYG); [forum, 6 October 2022](https://gsap.com/community/forums/topic/34136-animating-cards-on-hover-is-this-a-good-use-case-for-the-flip-plugin/); [Flip is listed on the docs index](https://gsap.com/docs/v3/)

4. **Scribble underline.** Pointer enter injects one of six hand-drawn SVG strokes and tweens `drawSVG` from `"0%"` to `"100%"` in 0.5s with `power2.inOut`; leave tweens to `"100% 100%"` and then removes the SVG. Feature: DrawSVGPlugin, which the same article describes as tweening `stroke-dasharray` and `stroke-dashoffset`. It does not paint fills. Letters: yes, under the word. Tiles: only as a stroke under or around the tile, not across the bitmap. Not a duplicate: highlighter is a canvas brush that follows the cursor and fades; this is one stroke that draws on and erases. A CSS catalog already covers a growing rule and a rectangular dash-offset border; this card is the hand-drawn path and the two-value `drawSVG` syntax. Knob: duration and stroke color (`currentColor` in the demo). Extra script optional. Core fallback: set `strokeDasharray` to the path length and tween `strokeDashoffset`. — [Codrops, 14 May 2025, DrawSVG section](https://tympanus.net/codrops/2025/05/14/from-splittext-to-morphsvg-5-creative-demos-using-free-gsap-plugins/)

5. **Clip-path polygon wipe.** Pointer enter tweens `clip-path` from a collapsed polygon toward the full box; leave reverses. Feature: core `clipPath`. Codrops, 27 May 2025, builds a product-grid hover that opens a preview with GSAP `clip-path` (the author starts from Clippy’s cross polygon and reshapes it), moves neighboring cards, and debounces `mouseenter`. Letters: yes, one clip on the line. Tiles: yes. Not a duplicate: spotlight is a circular color window that follows the cursor; pixelate is a block window; this is a geometric wipe that opens and closes. Knob: duration and which polygon it starts from. The published piece expands into a preview and shifts the grid. On a lab card the wipe should stay inside the card. — [Animated Product Grid Preview](https://tympanus.net/codrops/2025/05/27/animated-product-grid-preview-with-gsap-clip-path/)

6. **Alternating clip slices.** Pointer enter runs pre-cut vertical or horizontal slices from alternating `yPercent` or `xPercent` offsets back to 0; leave sends them out again. Feature: core `clipPath` plus `yPercent` / `xPercent`. Codrops, 21 June 2023, sets a polygon clip per slice with `gsap.set`, then on `mouseEnter` runs `fromTo` to 0. Odd slices use `gsap.utils.random(-75, -25)`, even slices `random(25, 75)`. Defaults: `slicesTotal: 5`, `duration: 0.5`, `ease: "power3.inOut"`. Other published presets use 15 slices and `duration: 0.6`, `ease: "expo.inOut"`. `mouseLeave` tweens the slices back to random offsets and the image to `yPercent`/`xPercent` 100 with `opacity: 0`. Letters: weak, unless the headline is cut into strips. Tiles: yes. Not a duplicate: shatter spins angular shards off; glitch slips scanlines with a cyan/magenta fringe. These strips are a staged offset of a flat image. Knob: slice count, duration, orientation. The same article also shuffles characters with Splitting.js; that shuffle is the scramble card and should not be built. The published rest state is the image hidden. For the lab, invert it: rest at 0, hover offsets the slices, leave tweens back to 0. — [Sliced Image Hover](https://tympanus.net/codrops/2023/06/21/coding-the-sliced-image-hover-effect-from-quai-network/)

7. **Distance color fill.** While the pointer is inside, each piece’s color moves from a base to an active color by distance; past the threshold it is the base color again, so leave restores it. Feature: core `backgroundColor` or `color`, set with `gsap.utils.interpolate`. In the 14 May 2025 dot grid, `t = Math.max(0, 1 - dist / threshold)` and `gsap.set(el, { backgroundColor: col })` runs on every move. The same handler’s inertia push is the lab’s inertia card and should be dropped. Letters: yes (`color`). Tiles: yes (`backgroundColor` or a flat tint). Not a duplicate: duotone and glow are canvas pixel and halo effects; scramble changes glyphs, not a flat fill. Knob: threshold (the lab’s shared radius is the same idea) and a target color. No extra plugin. — [Codrops, 14 May 2025, dot grid](https://tympanus.net/codrops/2025/05/14/from-splittext-to-morphsvg-5-creative-demos-using-free-gsap-plugins/)

8. **Motion-path trace.** A bead, or a small duplicate of a tile, travels an SVG path of the mark. Play and reverse on leave, or set the tween’s progress from pointer x while the pointer is inside. Feature: MotionPathPlugin. Docs: `path` may be an SVG path, path data, or an array of `{x, y}` points; `align`, `alignOrigin: [0.5, 0.5]`, `autoRotate`, `start`, and `end` are the usual options; `convertToPath()` turns basic SVG shapes into paths. `align` is described as GSAP-specific. The docs demo is `duration: 5` with `yoyo: true`, not a hover. The official paired pen loops an airplane (`repeat: -1`) and draws the route with DrawSVG. Letters: a bead along a path under the word, unless the word is already an SVG path. Tiles: yes for an SVG mark; a raster logo needs an authored path or a point array. Not a duplicate: orbit circles the live cursor; swirl twists pixels; this follows a fixed path. Knob: the path, plus duration or scrub. Extra script. Core fallback: sample the path to points and tween `x` / `y`. MotionPathHelper is an editor, not required at runtime. quickTo cannot carry `motionPath`; the docs say quickTo skips plugin parsing. — [MotionPath](https://gsap.com/docs/v3/Plugins/MotionPathPlugin/); [MotionPath & DrawSVG pen](https://codepen.io/GreenSock/pen/gONoYaG); [quickTo limits](https://gsap.com/docs/v3/GSAP/gsap.quickTo()/)

9. **Elastic drag home.** Pointer down pulls a letter or tile; release tweens `x: 0, y: 0` with `elastic.out`. Feature: Draggable, then a core tween. A 26 May 2025 forum thread asks for alphabet characters to spring home after drag. The working fix, in pen `emNmKQV`, is `gsap.to(char, { x: 0, y: 0, duration: 0.5, ease: "elastic.out" })` inside `onDragEnd`, using the loop variable rather than `event.target`. An earlier suggestion that tweened `this.deltaX` / `this.deltaY` did not return home. Letters: yes, the thread is about alphabets. Tiles: the same call. Not a duplicate: inertia throws with velocity and settles; elastic pop scales; this is a drag away from the origin and a spring back, with no throw. Knob: the home tween’s duration. Extra script. Core fallback: pointer handlers and the same `elastic.out` home tween. Do not set `inertia: true` or it becomes the inertia card. This is pointer-down, not mouseenter. — [forum, 26 May 2025](https://gsap.com/community/forums/topic/44625-need-the-characters-spring-back-to-their-original-position-after-dragging-using-draggable-and-inertia-plug-in-not-working-need-help/); [pen emNmKQV](https://codepen.io/GreenSock/pen/emNmKQV)

10. **Overshoot follow, no ghosts.** While the pointer is inside, each piece’s `x` and `y` chase a small offset toward the cursor and pass that target before settling; leave sends them to 0. Feature: `gsap.quickTo` whose ease overshoots. The official follower uses `power3`, which settles without passing the target (durations 0.4 and 0.6 in the two docs samples). The May 2025 drag thread uses `ease: "elastic.out"` for a return that springs past rest. Putting that ease on the follow, and not on scale, is the missing combination. Letters: yes. Tiles: yes, on the same DOM pieces the GSAP cards already build. Not a duplicate: Echo is canvas pieces that chase and leave ghost copies; orbit is circular motion; elastic is scale. Knob: follow duration and the overshoot ease. No extra plugin. This one is a composition of the quickTo docs and the forum ease, not a single published demo. — [quickTo](https://gsap.com/docs/v3/GSAP/gsap.quickTo()/); [forum ease](https://gsap.com/community/forums/topic/44625-need-the-characters-spring-back-to-their-original-position-after-dragging-using-draggable-and-inertia-plug-in-not-working-need-help/); Echo blurb in `index.html`

11. **Lagged swing and brightness.** Pointer move lags a piece’s `x`, `y`, and 2D `rotation` behind the cursor and raises CSS `brightness`; leave returns `x`, `y`, and `rotation` to 0 and brightness to 1. Feature: core transforms. Codrops, 1 July 2020, reveals a menu image with a GSAP `x` from `100%` or `-100%` (`Sine.easeOut`, about 0.2s) and then, in a render loop, `gsap.set`s `x`, `y`, `rotation`, and `filter: brightness(...)` from lerped pointer values. The published subject is a photo beside menu text, not a logo. Letters: yes, the same properties on each glyph. Tiles: yes. Not a duplicate: smear writes `skewX` from velocity; 3D flip uses `rotationX` / `rotationY`; glow is a canvas halo, not a uniform brightness filter. Knob: lag amount and max rotation. No extra plugin. — [Menu image hover, 1 July 2020](https://tympanus.net/codrops/2020/07/01/creating-a-menu-image-animation-on-hover/)

12. **Simple-shape morph, weak fit.** Pointer enter morphs one SVG `d` into another; leave morphs back. Feature: MorphSVGPlugin. The 14 May 2025 demo is a click, not a hover: a play path morphs to a pause path in 0.5s, `power4.inOut`, with `type: "rotational"` and `map: "complexity"`, which the article says works when point counts differ. It can target simple shapes. It cannot target the lab’s raster tiles or HTML letters. Core fallback for a same-count polygon: tween `clip-path`, as in finding 5. Mark optional. It does not earn a card unless the subject becomes an SVG path. — [Codrops, 14 May 2025, MorphSVG section](https://tympanus.net/codrops/2025/05/14/from-splittext-to-morphsvg-5-creative-demos-using-free-gsap-plugins/)

**Rejected as duplicates or as the wrong gesture**

- Physics2D letters in the same 14 May 2025 article fall off the viewport on scroll (`velocity: "random(500, 1000)"`, `gravity: 3000`) and fade out. They do not return. That restates shatter and explode. — [same article](https://tympanus.net/codrops/2025/05/14/from-splittext-to-morphsvg-5-creative-demos-using-free-gsap-plugins/)
- The inertia push and click shockwave on that article’s dot grid restate GSAP inertia. Only the distance color is new (finding 7). The article itself says a canvas or WebGL grid would be the faster version of the same dots.
- Codrops, 16 June 2023, ships eight GSAP line-and-letter hovers (demo titles Ebullient through Urbane). The article does not name the eight motions. A third-party walkthrough of one of them scatters characters with random `xPercent` / `yPercent` (±150), `rotation` (±25), and `scale` (1 to 1.5) at `stagger: 0.03`, which restates explode, beside a `scaleX` line that a CSS underline already covers. — [article](https://tympanus.net/codrops/2023/06/16/4-exclusive-demos-slideshows-typographic-animations/); [demo](https://tympanus.net/Development/LineTypeEffect/); [repo](https://github.com/codrops/LineTypeEffect); [walkthrough](https://medium.com/@vaghani.dhruv41/line-letter-hover-animations-561ea068f8b5)

### Inferences
- The lab’s GSAP cards tween transforms on pieces that already exist (scale, x/y, rotation, skew, character jitter). The missing GSAP-specific work is layout measurement (Flip), stroke progress (DrawSVG), a path parameter (MotionPath), and text structure (SplitText masks). Color, clip, swing, and overshoot can stay on core.
- quickTo is already the orbit and smear engine (`index.html` builds `quickTo` for `x`, `y`, `scale`, `rotation`, `rotationX`, `rotationY`, and `skewX`). Reusing it is a new card only when the motion is not circular and the property is not `skewX`.
- A raster logo cannot grow a DrawSVG stroke or a MotionPath unless the card adds an SVG path or a point array. Letters can take a stroke under the word with no asset work. That split should decide which cards are headline-first.

### Gaps
- No Codrops or GreenSock hover article dated 2026 was found. The latest GSAP hover posts opened were May 2025.
- No official demo was found that maps pointer velocity to inverse `scaleX` / `scaleY`. Squash-and-stretch on velocity stays unconfirmed. Jelly already squashes a canvas mesh, and smear already writes `skewX`.
- No published hover was found of MotionPath tracing a logo. The GreenSock pen loops. A hover-scrub wiring was not opened.
- No hover rolling-counter (slot / odometer) demo was opened. The masked `yPercent` wipe is the nearest sourced mechanism; a drum of duplicate glyphs would be an adaptation, not a cited demo.
- No character-rotation marquee whose hover seeks the row home was opened. The June 2023 letter set is hover, but the one walked-through variant scatters letters rather than looping them.
- `edgeResistance` on Draggable was not fetched. The May 2025 thread’s verified behavior is the elastic return to 0,0, not a rubber edge.
- The eight LineTypeEffect motions were not listed in the article, and `src/js/index.js` on the repo returned 404. Only one variant was read, via a Medium walkthrough.
- GSAP Vault and similar galleries were not used. Live CodePens were not executed. Behavior is taken from published source in the articles, docs, and pen HTML returned by search.
- The 1 March 2023 Codrops double-image clip-path article was not re-fetched here. A sibling CSS note already flags its glitch variant as the canvas glitch card.

## Which of those are real hover fidgets on the artwork, rather than page-load animations?

### Takeaway
Seven are published as pointer enter, move, or leave on a visual the user is pointing at: kinetic rows, FLIP flex, scribble underline, clip-path wipe, clip slices, distance color, and lagged swing. Masked wipe, MotionPath, and MorphSVG are click, loop, or load in the source. Elastic drag is a press. Overshoot follow is not a published effect. Only the seven, plus overshoot follow after the ease change, match “hover disturbs the artwork, leave sends it home” without rewriting the trigger. Slices and the product-grid clip need the direction or the frame constrained so the logo is what moves.

### Cited Findings
- **Already a hover on the artwork.** Kinetic rows: Codrops 29 May 2024 describes text rows, and an image-grid variant, moving with the mouse. The click-to-fullscreen in that article is a separate intro. FLIP flex: the GreenSock pen listens to `mouseenter` and `mouseleave` on each cell. Scribble underline: Codrops 14 May 2025 draws on `mouseenter` and erases on `mouseleave`. Clip slices: Codrops 21 June 2023 animates on enter and leave; leave sends the image away, so the published “home” is hidden rather than assembled. Distance color: the dot handler updates color on `mousemove` by distance, so leaving the threshold restores the base color. Lagged swing: the 1 July 2020 menu effect follows the pointer for as long as the item is hovered. Clip-path wipe: Codrops 27 May 2025 is a real `mouseenter` / `mouseleave`, and the artwork becomes a product preview that leaves the cell.
- **Hover exists, but the sampled motion is explode.** The June 2023 line-and-letter set is hover on words. The one variant whose tween was read scatters letters with random x, y, rotation, and scale.
- **Not hover in the source.** The masked wipe’s buttons are clicks; the article names scroll and load as the production triggers. MotionPath’s docs demo yoyos over 5 seconds; the GreenSock pen repeats forever. MorphSVG’s play/pause is a click. Physics2D smash is ScrollTrigger `once: true`. Overshoot follow is quickTo plus an ease taken from the drag-home thread. Elastic drag is `onDragEnd`, which fails a strict hover-only reading, and it does return letters to 0,0.

### Inferences
- Build first, because the gesture already matches the lab: scribble underline, FLIP flex, kinetic row tracking, distance color, lagged swing, and overshoot follow (core only, and clearly not Echo). Keep the clip-path wipe inside the card.
- Build after inverting the rest pose: alternating slices (rest assembled, hover offsets, leave returns to 0). Drop the character shuffle.
- Build after changing the trigger: masked wipe (enter plays, leave reverses). Hold MotionPath until a card has a path. Hold MorphSVG until the subject is an SVG path. Hold elastic drag if the lab rule is hover with no press.

### Gaps
- “Hover fidget” versus “hover that starts a page-sized preview” is a judgment. The 27 May 2025 clip demo is a real hover, and it leaves the grid. These notes treat the clip tween as the fidget and the preview takeover as out of scope for one card.
- Whether every one of the eight June 2023 letter hovers returns home was not verified. Only one variant’s tween was read.
- The 29 May 2024 article’s exact tween (quickTo versus a custom lerp) was not in the fetched summary. The motion is described; the GSAP call is inferred from the article’s GSAP tag plus the quickTo docs, not copied from that article’s script.

## What extra knob would the lab need?

### Takeaway
Duration and stagger already exist on GSAP cards. Smear has duration and no separate skew amount. The new knobs are a path, a clip polygon, a slice count, a fill color, a flex ratio, a follow lag, and an overshoot ease. Flip, MotionPath, DrawSVG, SplitText, MorphSVG, and Draggable are extra scripts on the same free 3.13 CDN, not a paid upgrade. Do not add a skew knob.

### Cited Findings
- Existing GSAP knobs in `index.html` `EXTRA`: elastic uses scale and duration; explode, scramble, swap, and cascade use duration and stagger; 3D flip uses tilt and duration; wiggle, inertia, orbit, and smear use duration. Shared controls are radius and strength. Nothing in that map is a path, a clip, a stroke, or a layout ratio.
- Per effect, the knob the source actually exposes: masked wipe — stagger and duration, with a different pair for lines, words, and letters so a long letter stagger does not run forever (Codrops 14 May 2025). Kinetic row — quickTo `duration` (0.6 and `power3` in the official follower). FLIP — `duration` (the pen uses 1) and the CSS flex ratio (`flex-basis: calc(150% - 5px)`). Scribble — duration 0.5 and `power2.inOut`, plus stroke color. Clip wipe — duration and the starting polygon. Slices — `slicesTotal` (5 or 15), duration (0.5 or 0.6), and orientation (`vertical` or `horizontal`). Color fill — distance threshold and the two colors passed to `gsap.utils.interpolate`. Motion path — `path`, `alignOrigin`, `autoRotate`, `start` / `end`. Elastic drag — home duration 0.5 and `elastic.out`. Overshoot follow — quickTo duration and an ease that passes the target (`elastic.out` is the one the forum names). Swing — the lerp amount and the rotation fed into `gsap.set`.
- Plugin cost: the 29 April 2025 3.13 post put the former Club plugins in the public package. The docs index lists DrawSVG, MorphSVG, MotionPath, SplitText, Flip, and Draggable with CDN marks. The lab’s script tags stop at CustomEase, InertiaPlugin, and CustomWiggle. Core-only cards (clip wipe, color fill, overshoot follow, kinetic row, swing, and a handmade masked wipe) need no new script.
- quickTo is the wrong tool for DrawSVG and MorphSVG. The docs say it skips plugin parsing and cannot take a `morphSVG` value.

### Inferences
- One shared stagger knob covers the masked wipe. One shared duration covers almost everything else. Do not add a skew knob; smear already owns skew.
- Add a path control only on the motion-path card, and a stroke only on the underline card. For raster logos that control is an authored SVG or a point array, which the current tile pipeline does not have.
- Add a flex ratio only if FLIP ships, a slice count only if slices ship, and a target color only if the distance fill ships. The lab’s radius can stand in for the color threshold.
- Prefer core fallbacks on the first build: clip wipe, color fill, overshoot follow, kinetic row, swing. Load Flip or DrawSVG only for the cards whose point is that plugin.

### Gaps
- Whether the global strength slider already scales GSAP distances was not read out of `gsapFx`. The `EXTRA` table is what was confirmed.
- Exact jsDelivr filenames for Flip, DrawSVG, MotionPath, SplitText, MorphSVG, and Draggable were not fetched. Only the existing `gsap@3.13.0/dist/*.min.js` pattern, the 3.13 public-package statement, and the docs CDN list were confirmed.
